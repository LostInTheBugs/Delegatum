DELEGATUM — APPLICATION DE BUREAU (Windows)
=============================================

🌍 Autres langues : English → README.txt · Deutsch → LIESMICH.txt ·
   Lëtzebuergesch → LIES-MICH.txt

Gestion de votre délégation du personnel (Luxembourg), sur VOTRE ordinateur.
Aucun serveur, aucun compte en ligne, aucune connexion requise : vos données
ne quittent pas la machine.

INSTALLATION (2 minutes, sans installateur)
-------------------------------------------
1. Décompressez le dossier « Delegatum-Windows » où vous voulez
   (par exemple : Documents\Delegatum). Évitez de le placer dans
   « Program Files », Windows y bloque l'écriture des données.
2. Double-cliquez sur « Delegatum.exe ».

   Premier lancement : Windows peut afficher « Windows a protégé votre PC »
   (SmartScreen, normal pour une application non signée). Cliquez sur
   « Informations complémentaires » puis « Exécuter quand même ».

   Windows Defender peut aussi signaler un cheval de Troie : c'est un FAUX
   POSITIF connu des applications non signées. Cliquez sur l'alerte →
   « Actions » → « Autoriser sur l'appareil ».

3. La fenêtre Delegatum s'ouvre sur l'écran « Créer une délégation du
   personnel » (premier lancement uniquement).

PREMIERS PAS
------------
Au premier lancement, créez votre délégation :
   - nom de l'organisation, effectif de l'entreprise ;
   - coordonnées du/de la président(e) : ce premier compte est
     l'administrateur de l'application.

Ensuite : « 🔑 J'ai déjà un accès » pour vous connecter. Les autres membres
rejoignent avec un code d'invitation à distribuer (bouton « ✉️ Créer un accès »).

VOS DONNÉES
-----------
Tout est dans le dossier « data », à côté de Delegatum.exe :
   - delegatum.db   : la base (membres, réunions, PV, élections, heures…) ;
   - .secret_key    : clé de signature locale — ne pas la partager ;
   - emails\        : notifications préparées (fichiers .eml à envoyer).

Sauvegarder = copier ce dossier « data » sur une clé USB ou un disque externe
de temps en temps. Restaurer = remettre le dossier au même endroit.

CONFIDENTIALITÉ
---------------
Rien n'est envoyé sur Internet. Les procès-verbaux (PV) sont chiffrés dans
l'application (AES-256-GCM) avec un mot de passe de coffre-fort : même les
fichiers du dossier « data » ne les contiennent pas en clair. Conservez la
clé de récupération du coffre (`Paramètres`) dans un endroit sûr.

POUR FERMER
-----------
Fermez la fenêtre (la croix). Le logiciel s'arrête — aucun service ne reste
en arrière-plan.

DÉPANNAGE
---------
- « Windows a protégé votre PC » : normal (application non signée), voir
  point 2.
- La fenêtre ne s'ouvre pas : vérifiez qu'un antivirus ne bloque pas
  Delegatum.exe, puis relancez.
- Repartir de zéro : fermez l'application et supprimez le dossier « data »
  (⚠️ tout est effacé — faites d'abord une sauvegarde si nécessaire).
- Changer d'ordinateur : copiez le dossier « data » à côté du nouveau
  Delegatum.exe.
